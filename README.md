# Умный дом — панель управления (PWA) + Arduino Nano

Веб-приложение для управления умным домом: свет, LED-подсветка, отопление, циркуляционный насос, кондиционер, шторы, сценарии и голосовое управление. Панель работает как устанавливаемое PWA-приложение (можно поставить на рабочий стол телефона/компьютера) и связывается с Arduino Nano по USB через Web Serial API.

## Состав системы

### Управляемые устройства и их выводы (Arduino Nano)

| Пин | Устройство | Тип |
|---|---|---|
| D2  | Нагреватель | Реле |
| D3  | LED-подсветка (яркость) | PWM |
| D4  | Основное освещение | Реле |
| D5  | Вентилятор кондиционера (скорость 1–3) | PWM |
| D6  | Циркуляционный мотор — 12В помпа | MOSFET/реле |
| D7  | Питание кондиционера | Реле |
| D8–D11 | Шторы (шаговый двигатель) | 28BYJ-48 + ULN2003 |
| D12 | Датчик температуры DS18B20 *(опционально)* | OneWire |

> Разводка — примерная. При необходимости измените номера пинов в `smart_home_nano.ino`.

## 1. Прошивка Arduino

### Требуемые библиотеки

Установите в Arduino IDE (Менеджер библиотек: **Скетч → Подключить библиотеку → Управлять библиотеками**):

- **AccelStepper** — обязательно (шаговый двигатель штор).
- **OneWire** + **DallasTemperature** — только если включён датчик температуры (`USE_TEMP_SENSOR 1`).

### Настройка

1. Откройте `smart_home_nano.ino` в Arduino IDE.
2. При необходимости включите датчик температуры — в верхней части файла поменяйте:
   ```cpp
   #define USE_TEMP_SENSOR 0   // 1 — включить DS18B20 на пине D12
   ```
3. Выберите плату **Arduino Nano** (**Инструменты → Плата → Arduino Nano**) и процессор **ATmega328P (Old Bootloader)**, если используется китайская копия Nano.
4. Подключите Nano по USB и выберите нужный COM-порт (**Инструменты → Порт**).
5. Нажмите **Загрузить** (→).

После загрузки шторы калибруются: двигатель стоит в начальной позиции (0% = шторы открыты, 100% = закрыты, 4000 шагов).

### Протокол связи

Скорость **9600 бод**, команды — строка с символом перевода строки `\n`:

| Команда | Значение | Описание |
|---|---|---|
| `L=0|1` | 0/1 | Основное освещение |
| `LED=0..100` | число | Яркость подсветки |
| `TEMP=15..30` | число | Целевая температура отопления |
| `PUMP=0|1` | 0/1 | Циркуляционный мотор |
| `AC=0|1` | 0/1 | Кондиционер вкл/выкл |
| `ACMODE=cool\|heat\|dry\|auto` | строка | Режим кондиционера |
| `ACTEMP=16..30` | число | Температура кондиционера |
| `ACFAN=1..3` | число | Скорость вентилятора |
| `CUR=0..100` | число | Шторы (0 — открыто, 100 — закрыто) |
| `SCENE=home\|evening\|cinema\|morning\|night\|away` | строка | Сценарий |
| `?` | — | Запрос состояния (Arduino вернёт `L=...;LED=...;...`) |

## 2. Запуск панели

Приложение **не работает по двойному клику** (`file://`): Web Serial и PWA требуют защищённого контекста (HTTPS или `localhost`). Нужен локальный сервер.

### Способ А — Python (самый простой)

Из папки проекта:

```bash
cd "C:\Users\user\Desktop\Прект Дани"
python -m http.server 8080
```

Откройте в браузере: **http://localhost:8080/smart_home.html**

### Способ Б — Live Server (VS Code)

1. Установите расширение **Live Server** в VS Code.
2. Откройте папку проекта и кликните правой кнопкой по `smart_home.html` → **Open with Live Server**.

### Способ В — Node.js

```bash
npx serve .
```

Откройте указанный локальный адрес.

### Требования к браузеру

- **Chrome** или **Edge** (актуальная версия) — поддержка Web Serial API и установки PWA.
- Браузер должен открывать страницу по **http://localhost** или **https://** (на `file://` приложение не полноценно заработает).

## 3. Установка приложения (PWA)

Откройте панель через локальный сервер, затем:

### Компьютер (Chrome/Edge)

- Нажмите иконку **Установить** в адресной строке справа (или **Установить приложение «Умный дом»** в меню браузера).
- Либо нажмите кнопку **«Установить»** прямо в шапке панели (она появляется, когда браузер готов к установке).

### Телефон (Android)

1. Откройте панель в Chrome на телефоне.
2. Меню → **Добавить на главный экран** → **Установить**.
3. Приложение появится на рабочем столе как полноэкранное (без адресной строки), с иконкой дома.

> PWA работает офлайн: после первого открытия панель, шрифты и иконки кэшируются service worker. Сценарии, быстрые команды и управление отвечают и без интернета (погода — только онлайн).

### Быстрые сценарии с главного экрана

При установке добавляются ярлыки (shortcuts) в длинном нажатии на иконку:

- **Утро** → `?scene=morning`
- **Ночь** → `?scene=night`
- **Пока** → `?scene=away`

## 4. Подключение Arduino к панели

1. Запустите панель через локальный сервер (см. раздел 2).
2. Убедитесь, что Nano подключён к компьютеру по USB и прошит (раздел 1).
3. В шапке панели нажмите кнопку **Arduino**.
4. Заголовке появится запрос на выбор USB-порта — выберите порт Nano (**COMxx**).
5. Статус сменится на **«нано подключён · 9600»**.

Теперь переключатели, ползунки и сценарии на панели сразу отправляют команды в Arduino (`L`, `LED`, `TEMP`, `PUMP`, `AC`, `ACFAN`, `CUR`, `SCENE` и т.д.).

## 5. Голосовое управление

Панель использует Web Speech API (распознавание речи браузером, язык `ru-RU`).

1. Нажмите пиктограмму **микрофона** в карточке «Голос» (разрешите доступ к микрофону).
2. Скажите слово **«дом»** — панель «проснётся», затем произнесите команду.
3. Можно сразу: **«дом, температура 24 градуса»**.

### Основные команды

- «включи свет» / «выключи свет» / «выключи подсветку»
- «температура 24 градуса» / «яркость 50 процентов» / «увеличь яркость»
- «включи мотор»
- «шторы наполовину» / «закрой шторы на 50 процентов» / «закрой шторы» / «раздвинь шторы»
- «включи кондиционер» / «выключи кондиционер»
- «включи охлаждение 24 градуса» / «обогрев» / «осушение»
- «кондиционер в авто-режиме» / «скорость вентилятора выше» / «скорость вентилятора ниже»

### Сценарии голосом

«привет, я дома», «вечер», «кино», «утро», «ночь», «я ушёл», «пока»

### Автоматика

- При **снижении** температуры отопления кондиционер сам включается в режиме **«авто»** на эту же температуру.
- При **повышении** (нужно отопление, а не охлаждение) кондиционер выключается.

## 6. Сценарии

Кнопки в нижней части панели (и голосовые команды):

| Сценарий | Действия |
|---|---|
| **Привет, я дома** | Свет вкл, подсветка 75%, 24 °C, мотор вкл, шторы открыты |
| **Наступил вечер** | Свет выкл, подсветка 50%, 21 °C, шторы закрыты |
| **Кино** | Шторы закрыты, подсветка 25% |
| **Утро** | Шторы открыты, подсветка 40%, 22 °C |
| **Ночь** | Свет выкл, подсветка выкл, 19 °C, шторы закрыты |
| **Я ушёл / Пока** | Свет выкл, 19 °C (кондиционер и мотор гаснет в прошивке) |

Точный набор действий сценария можно менять в коде панели (объект `scenarios` в `smart_home.html`) и в прошивке (функция `runScene` в `.ino`).

## 7. Структура и настройка

### Панель (`smart_home.html`)

- **CSS/JS/HTML** в одном файле — удобно переносить.
- **Карточки** расположены сеткой на один экран; при переполнении панель автоматически масштабируется (`fitToScreen`), компактный режим включается при высоте окна ≤ 1180 px.
- **Погода**: загружается с Open-Meteo по координатам Нижнего Новгорода (нужен интернет). Координаты можно поменять в функции `fetchWeather()`.
- **Шрифты**: Material Symbols Rounded грузятся с Google Fonts (кэшируются service worker после первого запуска).
- **Название/цвета**: переменные в блоке `:root` (`--accent`, `--green` и т.д.).

### Прошивка (`smart_home_nano.ino`)

- Пины в `const int PIN_... = N;` в начале файла.
- Калибровка штор: `CURTAIN_MAX_STEPS = 4000` — подстройте под реальное количество шагов вашего механизма.
- Климат-автоматика (нагрев/вентилятор по температуре) работает при `USE_TEMP_SENSOR 1`.

## 8. Возможные проблемы

| Проблема | Решение |
|---|---|
| Кнопка «Arduino» недоступна / Web Serial не предлагается | Откройте страницу через http://localhost (не `file://`). Используйте Chrome/Edge. Включите в настройках сайта разрешение на **Порты** (Serial). |
| Не распознаётся голос | Проверьте доступ к микрофону, используйте Chrome/Edge, говорите команду после слова «дом» и проверьте, что в системных настройках выбран русский микрофон. |
| Погода не загружается | Нет интернета или заблокирован запрос к Open-Meteo. Остальное управление продолжает работать. |
| Ползунки реакции нет / устройства не двигаются | Проверьте, что панель открыта по localhost, Nano выбран в диалоге Arduino, провод не только зарядочный (должен передавать данные), COM-порт определяется системой. |
| Шторы ходят не на полный ход | Увеличьте `CURTAIN_MAX_STEPS` и перепрошейте. |
| Ошибка компиляции прошивки | Установите библиотеку **AccelStepper** через менеджер библиотек. |
| PWA не предлагает установку | Откройте через https/localhost, обновите страницу повторно (после первого захода кэшируется манифест). Пустой кэш не критичен — повторный заход решает. |
